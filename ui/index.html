Never merge these addresses

Traffic to these IPs skips NetMerge and uses normal Windows routing — for example a Remote Desktop server reached through your VPN.

Keep these websites on one connection

Banks and login pages can sign you out if your IP changes between requests. These stay on a single link.

VPN connection

VPN tunnels (SonicWALL, Cisco, FortiClient, OpenVPN…) are kept on one link so they never break.

Built-in DNS

Off (recommended): Windows and your VPN keep handling name lookups. On: NetMerge resolves names itself, which may break company-only addresses.

Block ads & trackers

NetMerge refuses connections to known ad, tracking and malware websites before they use your internet. It works for every app, while merging is on.
