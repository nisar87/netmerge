Routing exceptions

You normally do not need anything on this page. These are exceptions for special cases (a company VPN, a bank that signs you out, a Remote Desktop server). Leave them empty if none of that applies to you.

Skip NetMerge for these addresses Only if needed

Traffic to these IPs skips NetMerge and uses normal Windows routing — for example a Remote Desktop server reached through your VPN.

Keep these websites on one line Only if needed

Banks and login pages can sign you out if your IP changes between requests. These stay on a single link.

Line used by your VPN Only if you use a VPN

VPN tunnels (SonicWALL, Cisco, FortiClient, OpenVPN…) are kept on one link so they never break.

Block ads & trackers

NetMerge refuses connections to known ad, tracking and malware websites before they use your internet. It works for every app, while merging is on.

Merge automatically Recommended: onMerging turns on as soon as NetMerge starts. If off, you press the Merging switch each time.
Protect calls and meetings Recommended: onTeams, Zoom, Discord and similar stay on one steady connection, and big downloads are kept off that line during a call. If off, a call may stutter while you download.
